## ⚠️ 别和补丁版同时装

玩家补丁合集 `uranus_patches_awesome` 的 **01 模块「常驻运行日志抽屉」** 和本插件是**同一个东西的两种装法**。**只装一个**——两个都装会冒出两个日志入口（角落两个胶囊 / 面板重叠）。

| 你想用 | 那就别装 |
|---|---|
| 本插件 | 01 模块 |
| 01 模块补丁 | 本插件 |

两者功能一致（筛选级别、拖动记忆落点都照原版复刻），插件版的好处是不用改源码、Uranus 升级不会被覆盖、装卸在控制台点一下。

## 这个插件做什么

在任意页面的角落钉一个实时运行日志窗。等模型出字时不用切去「控制台」，就能看清到底是"在慢慢生成"还是"API 已经断了"。

**界面和功能照原版复刻：**

| 原版有的 | 插件是否复刻 |
|---|---|
| "运行日志"标题 + 实时连接状态 | ✅ 已连接绿点脉冲 / 断开变红 |
| 五级筛选 DEBUG / INFO / WARNING / ERROR / CRITICAL | ✅ 完全一样，选某级=该级及以上 |
| 搜索关键词 | ✅ 搜正文、scope、detail |
| 暂停 / 继续（带待处理条数 +N） | ✅ |
| 清空 | ✅ |
| 日志行：毫秒时间、大写 scope、错误行软红底、detail 点开看原始内容 | ✅ 完全一样 |
| 问题条数角标（warn 以上） | ✅ 收成胶囊时也能一眼看出有没有报错 |
| 拖动到任意位置 + 记忆落点 + 边缘避让 | ✅ 气泡和整条标题栏都能拖 |
| 收成胶囊 / 展开 | ✅ |
| "默认展开"勾选 | ✅ |
| "回到最新"按钮 | ✅ 往上翻日志时不被新日志抢滚动条 |
| **模型快切**（聊天/线下/兜底三档） | ✅ 见下 |

## 模型快切怎么做到不依赖补丁的

原版的模型快切走 `POST /api/role-model`——这是**补丁加的服务端接口**，纯上游没有。插件用了两段式兜底：

1. **装了补丁**（有 `/api/role-model`）：直接调用，行为和原版一字不差。
2. **纯上游**（没这个接口）：插件自动回退成 `GET /api/config` → 只改选中角色那一档的模型引用 → `PUT /api/config` 整份写回。效果一样：切完就生效、落盘、跨设备。

> 回退路径走的是 `PUT /api/config`，它会让服务端重新对齐桥接连接（跟你在控制台点"保存"是同一条路）。所以**切模型前，如果别的面板有没保存的草稿，先存一下**——这点跟原版的 `/api/role-model`（只改一个字段、不整包覆盖）略有差别，是纯插件能做到的极限。

三档含义和原版一致：
- **聊天**：线上 iMessage 用的模型
- **线下**：线下剧情用的模型（没单独配时跟着聊天走）
- **兜底**：原"副 API"，主模型报错时顶上，聊天和线下共用

## 配置（插件设置页）

- **打开页面就展开**：默认开；关掉就只显示小胶囊。
- **最多留几行**：默认 2000（跟后端环形缓冲一致），超了丢最旧的。
- **默认最低级别**：默认 INFO，可设 DEBUG 看全部。

面板上的筛选、默认展开勾选会记住（存在浏览器本地）；位置也存在本地。

## 和原版唯一的差别

原版是 React 组件、直接复用全局 LogContext；插件是原生 DOM、自己订阅同一条 SSE。数据一模一样（都是 `/api/logs/stream` 那条流），样式也照原版设计变量复刻，所以看起来、用起来一致。唯一要注意的是上面模型快切的回退路径说明。

## 安装

解压后把整个目录放到 `data/plugins/`，在控制台"插件"页启用即可。改了配置刷新页面生效（上游的设计就是这样）。

地址栏加 `?noplugins` 可临时关掉所有插件做排查。
